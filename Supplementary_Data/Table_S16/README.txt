Solo-LTR diversity and expected nucleotide differences

The comparison includes 13 loci with at least 20 sampled sequences and 800 jointly callable LTR bases. Host flanks were removed by reference alignment. Tables include sample counts, substitution counts, callable denominators, exclusions and source paths. Expected differences are illustrative pairwise clock calculations, separate from the observed within-human diversity.

The retained mapping files and unique sequence FASTA document LTR boundaries. The analysis script requires the source catalog and the original sample-to-sequence mapping, identified in the provenance tables.

Final manuscript labels are Table S4 and Figure S22 (21 September 2026). See ../../FIGURE_TABLE_MAP.md. Portable release reproduction is documented in ../../analysis/september2026_revision/README.md. The scripts retained in this folder preserve original analysis provenance. Statements above about original-workspace requirements describe those historical scripts, not the portable release workflow.
