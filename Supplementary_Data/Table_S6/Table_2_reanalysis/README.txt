Table_2_ORF_recovery.tsv gives all intact and combined counts, including the pooled Env values retained for reconciliation.
Table_2_ORF_recovery_by_locus.tsv gives the corresponding per-locus counts.
Table_2_ORF_recovery_observations.tsv lists every long-read-positive donor-locus combination and whether the VCF-derived call recovers it. A nonrecovered call can be negative or unknown; the analysis does not reinterpret unknown calls as confirmed negatives.
provenance.json records the source file hashes, matched cohort, type assignment and original-total validation.
recompute_table2.py reproduces all these files from the frozen inputs and retained catalog. See the parent README for the command.

Type-I Env denotes only a theoretical N-terminally truncated product. Translation has not been demonstrated. These are sequence annotations, not measurements of protein expression or biological activity.
